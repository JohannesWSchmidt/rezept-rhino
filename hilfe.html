Hilfe & Kontakt

Frage, Fehler oder Wunsch? Schreib an rezept-rhino@protonmail.com – am einfachsten aus der App über Einstellungen → Feedback senden. Dann stehen App-Version, iPhone-Modell und iOS-Version schon in der E-Mail.

Familie anlegen und einladen

Beim ersten Start legst du eine Familie an, zum Beispiel „Familie Schmidt“. Unter Einstellungen → (Name deiner Familie) → Neuer Einladungscode erzeugst du einen Code und schickst ihn per Nachricht. Ein Code gilt sieben Tage und kann von mehreren Personen benutzt werden. Nur wer die Familie verwaltet, kann Codes erstellen.

Einer Familie beitreten

Gib den Code beim ersten Start unter Deiner Familie beitreten ein – oder später unter Einstellungen → (Familie) → Einer weiteren Familie beitreten oder eine anlegen. Groß- und Kleinschreibung und Bindestriche sind egal. Nach zehn falschen Codes innerhalb einer Stunde musst du kurz warten.

Rezepte hinzufügen

In der Rezeptliste über +: von einem Link, eine Kochbuchseite fotografieren, aus Fotos, als PDF oder Bild aus Dateien, oder selbst eintragen. Aus Safari und anderen Apps kannst du Seiten auch über Teilen → Rezept-Rhino schicken; sie warten dann unter Entwürfe. Vor dem Speichern prüfst du immer, was erkannt wurde.

Einkaufsliste

Im Rezept auf Zur Einkaufsliste tippen. Die Zutaten kommen – passend zur gewählten Portionenzahl – in eine Liste in Apple Erinnerungen.

Ein Rezept mit Freunden teilen

Im Rezept über Teilen → Rezept teilen. Du schickst einen Link; wer ihn öffnet und Rezept-Rhino hat, übernimmt das Rezept mit einem Tipp in die eigene Familie. Mitgeschickt werden Titel, Zutaten, Zubereitung, Foto, Quelle und dein Name – keine Tags, keine Originale, keine Kommentare. Der Link gilt 30 Tage. Spätere Änderungen am Rezept kommen nicht mit; teilst du es danach noch einmal, gibt es einen neuen Link. Für jemanden ohne App gibt es Als Text teilen.

Ein geteiltes Rezept übernehmen

Tippe auf den Link. Hast du Rezept-Rhino noch nicht, lade die App, melde dich an, lege deine Familie an und tippe dann noch einmal auf den Link. Klappt das nicht, gib den Code von der Seite, die der Link öffnet, in der Rezeptliste unter + → Code eingeben ein.

Sicherung

Einstellungen → Sicherung → Alle Rezepte exportieren erstellt eine Datei mit allen Rezepten, Fotos und Originalen deiner Familie. Mit Aus einer Datei importieren holst du sie wieder zurück, auch in eine andere Familie.

Familie verlassen

Einstellungen → (Familie) → Familie verlassen. Wer die Familie verwaltet, gibt die Verwaltung vorher an ein anderes Mitglied ab.

Konto löschen

Einstellungen → Konto löschen. Die App zeigt vorher, was mit jeder deiner Familien passiert. Einzelheiten stehen in der Datenschutzerklärung. Kommst du nicht mehr an die App, schreib uns.

Help & Contact

Question, bug or wish? Write to rezept-rhino@protonmail.com — easiest from the app with Settings → Send Feedback, which adds the app version, iPhone model and iOS version to the email for you.

Create a family and invite others

On first launch you create a family, say “The Smiths”. Under Settings → (your family's name) → New invite code you create a code and send it in a message. A code is valid for seven days and can be used by several people. Only the person who manages the family can create codes.

Join a family

Enter the code on first launch under Join your family — or later under Settings → (family) → Join or create another family. Upper or lower case and dashes don't matter. After ten wrong codes within an hour you have to wait a little.

Add recipes

Tap + in the recipe list: import from a link, photograph a cookbook page, pick from Photos, open a PDF or image from Files, or type it in. From Safari and other apps you can also use Share → Rezept-Rhino; shared pages wait under Drafts. You always check what was recognised before it is saved.

Shopping list

In a recipe, tap Add to shopping list. The ingredients — for the servings you chose — go to a list in Apple Reminders.

Share a recipe with friends

In a recipe, tap Share → Share Recipe. You send a link; anyone who opens it and has Rezept-Rhino adds the recipe to their own family with one tap. It carries the title, ingredients, steps, photo, source and your name — no tags, no originals, no comments. The link works for 30 days. Later changes to the recipe do not follow; share it again for a new link. For someone without the app, use Share as Text.

Add a recipe someone shared

Tap the link. If you do not have Rezept-Rhino yet, get the app, sign in, set up your family, then tap the link again. If that does not work, enter the code from the page the link opens under + → Enter Code in the recipe list.

Backup

Settings → Backup → Export all recipes creates one file with all of your family's recipes, photos and originals. Import from a file brings them back, into any family.

Leave a family

Settings → (family) → Leave family. Whoever manages the family hands that role to another member first.

Delete your account

Settings → Delete Account. The app shows beforehand what will happen to each of your families. Details are in the privacy policy. If you can no longer use the app, write to us.
